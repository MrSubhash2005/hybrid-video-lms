# Git Push Template

## Description
This template demonstrates the `git push` command using a terminal-style animation.

## Files
- `component.tsx` – Terminal UI component
- `scene.tsx` – Animation scene
- `data.json` – Sample input data
- `README.md` – Template documentation

## Sample JSON

```json
{
  "command": "git push origin main",
  "output": [
    "Enumerating objects: 12, done.",
    "Counting objects: 100% (12/12), done.",
    "Writing objects: 100% (12/12), done.",
    "To https://github.com/example/project.git",
    "   a1b2c3d..e5f6g7h  main -> main"
  ]
}
