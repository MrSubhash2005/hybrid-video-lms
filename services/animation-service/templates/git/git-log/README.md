# Git Log Template

## Description
This template demonstrates the `git log` command using a terminal-style animation.

## Files
- `component.tsx` – Terminal UI component
- `scene.tsx` – Animation scene
- `data.json` – Sample input data
- `README.md` – Template documentation

## Sample JSON

```json
{
  "command": "git log --oneline",
  "output": [
    "e5f6g7h Added subtitles",
    "c3d4e5f Added Git animations",
    "a1b2c3d Initial project setup"
  ]
}
