# Git Pull Template

## Description
This template demonstrates the `git pull` command using a terminal-style animation.

## Files
- `component.tsx` – Terminal UI component
- `scene.tsx` – Animation scene
- `data.json` – Sample input data
- `README.md` – Template documentation

## Sample JSON

```json
{
  "command": "git pull origin main",
  "output": [
    "From https://github.com/example/project",
    "* branch            main       -> FETCH_HEAD",
    "Already up to date."
  ]
}
