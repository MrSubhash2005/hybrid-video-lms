# Git Merge Template

## Description
This template demonstrates the `git merge` command using a terminal-style animation.

## Files
- `component.tsx` – Terminal UI component
- `scene.tsx` – Animation scene
- `data.json` – Sample input data
- `README.md` – Template documentation

## Sample JSON

```json
{
  "command": "git merge feature/subtitles",
  "output": [
    "Updating a1b2c3d..e5f6g7h",
    "Fast-forward",
    " subtitles.srt | 120 +++++++++++++++++++++++++",
    " 1 file changed, 120 insertions(+)"
  ]
}
