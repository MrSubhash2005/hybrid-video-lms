# Git Commit Template

## Description
This template demonstrates the `git commit` command using a terminal-style animation.

## Files
- `component.tsx` – Terminal UI component
- `scene.tsx` – Animation scene
- `data.json` – Sample input data
- `README.md` – Template documentation

## Sample JSON

```json
{
  "command": "git commit -m \"Initial project setup\"",
  "output": [
    "[main a1b2c3d] Initial project setup",
    "5 files changed, 120 insertions(+)",
    "create mode 100644 README.md",
    "create mode 100644 component.tsx",
    "create mode 100644 scene.tsx"
  ]
}
