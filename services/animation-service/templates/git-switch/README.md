# Git Switch Template

## Description
This template demonstrates the `git switch` command using a terminal-style animation.

## Files
- `component.tsx` – Terminal UI component
- `scene.tsx` – Animation scene
- `data.json` – Sample input data
- `README.md` – Template documentation

## Sample JSON

```json
{
  "command": "git switch feature/git-animation",
  "output": [
    "Switched to branch 'feature/git-animation'"
  ]
}
