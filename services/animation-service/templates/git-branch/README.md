# Git Branch Template

## Description
This template demonstrates the `git branch` . command using a terminal-style animation.

## Files
- `component.tsx` – Terminal UI component
- `scene.tsx` – Animation scene
- `data.json` – Sample input data
- `README.md` – Template documentation

## Sample JSON

```json
{
  "command": "git branch",
  "output": [
    "* main",
    "docs-testing",
    "feature/git-animation",
    "feature/subtitles"
  ]
}
