# Git Add Template

## Description
This template demonstrates the `git add .` command using a terminal-style animation.

## Files
- `component.tsx` – Terminal UI component
- `scene.tsx` – Animation scene
- `data.json` – Sample input data
- `README.md` – Template documentation

## Sample JSON

```json
{
  "command": "git add .",
  "output": [
    "Staging files...",
    "README.md",
    "component.tsx",
    "scene.tsx",
    "data.json",
    "Done."
  ]
}
