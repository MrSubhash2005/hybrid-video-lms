API Reference & Usage Documentation

Integrate celebrity course video generation into your application

POST /api/v1/course/generate

Queues or instantly returns a course video with voice narration for the specified celebrity.

Request Body (JSON)

{
  "course": "rag",        // Required: "git" | "rag" | "explainer" | "dsa"
  "celebrity": "Deepika", // Required: Any custom celebrity name
  "gender": "female"      // Optional: "auto" | "male" | "female"
}

Response (200 OK - Instant Cache / 202 Queued)

{
  "job_id": "job_39761b60",
  "status": "completed",
  "course": "rag",
  "celebrity": "Deepika",
  "gender": "female",
  "speaker": "shreya",
  "output_url": "/outputs/video_job_39761b60.mp4",
  "check_status_url": "/api/v1/course/jobs/job_39761b60"
}
GET /api/v1/course/jobs/:jobId

Check status and rendering progress percentage of a job.

GET /api/v1/cdn/stream/:filename

CDN streaming endpoint supporting HTTP Range byte seeking (`206 Partial Content`) for embedded video players.

Code Examples

curl -X POST http://localhost:3000/api/v1/course/generate \
  -H "Content-Type: application/json" \
  -d '{
    "course": "rag",
    "celebrity": "Shahrukh Khan",
    "gender": "male"
  }'
const response = await fetch('http://localhost:3000/api/v1/course/generate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    course: 'rag',
    celebrity: 'Deepika Padukone',
    gender: 'female'
  })
});

const data = await response.json();
console.log('CDN Video URL:', data.output_url);
import requests

url = "http://localhost:3000/api/v1/course/generate"
payload = {
    "course": "git",
    "celebrity": "Morgan Freeman",
    "gender": "male"
}

response = requests.post(url, json=payload)
data = response.json()
print("CDN Video URL:", data.get("output_url"))
